MOVIE INDUSTRY EDA

A Python-based exploratory data analysis project analyzing 7,500+ movies across four decades to identify the key factors associated with movie revenue and audience engagement.

PROJECT OVERVIEW

This project uses Python to explore movie industry data through data cleaning, statistical analysis, correlation analysis and visualization. The analysis focuses on understanding the relationship between movie budget, gross revenue, audience votes and IMDb scores.

KEY ANALYSIS

The analysis investigates which movie characteristics are most strongly associated with gross revenue and whether high audience ratings necessarily translate into higher earnings.

TOOLS & TECHNOLOGIES

Python   |   Pandas   |   NumPy   |   Seaborn   |   Matplotlib

KEY FINDINGS

  • Budget has the strongest correlation with Gross Revenue (r = 0.74).
  • Votes, representing audience engagement, have the second strongest correlation with Gross Revenue (r = 0.63).
  • IMDb Score has a relatively weak correlation with Gross Revenue (r = 0.19).
  • High movie ratings do not necessarily translate into high box-office earnings.

DATA ANALYSIS TECHNIQUES

Data cleaning and type conversion, missing-value handling, Pearson correlation, Kendall correlation, Spearman correlation, scatter plots, regression analysis and correlation heatmaps.
