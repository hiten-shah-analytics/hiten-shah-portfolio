COVID-19 DATA EXPLORATION

A SQL-based data exploration project analyzing COVID-19 cases, deaths, infection rates and vaccination progress across countries and continents.

PROJECT OVERVIEW

This project explores COVID-19 data using SQL to identify trends in cases, deaths, infection rates and vaccination progress. The analysis works with COVID deaths and vaccination datasets and develops queries for country-level, continent-level and global analysis.

KEY ANALYSIS

The analysis examines total cases versus deaths, percentage of the population infected, countries with the highest infection rates, countries with the highest death counts, continental death counts, global COVID-19 numbers and vaccination progress.

TOOLS & TECHNOLOGIES

SQL   |   Joins   |   CTEs   | Temp Tables   |   Window Functions   | Aggregate Functions   |   Views   | Data Type Conversion

SQL ANALYSIS OVERVIEW

The SQL analysis progresses from exploratory queries to more advanced techniques, including joins, common table expressions, temporary tables, window functions and a view created to support later visualizations.
